PM Chat — طرح رابط کاربری

برای اجرای محلی: pip install -r requirements.txt سپس uvicorn main:app --reload
مرورگر: http://127.0.0.1:8000

توجه: این نسخه فقط نمونهٔ رابط کاربری است. پیام‌ها در مرورگر آزمایشی‌اند و بین کاربران همگام نمی‌شوند؛ ثبت‌نام، پایگاه داده، ویس واقعی، استوری و آپلود هنوز به سرور وصل نیستند.
